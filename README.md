# Ejercicios de Lógica de Programación - TypeScript

Este repositorio contiene los ejercicios prácticos que resolví durante mi curso de "Programación para Principiantes" (DevTalles). A pesar de poseer cierto dominio en programación gracias a mi tecnicatura en desarrollo de aplicaciones y materias cómo Lógica de Programación y Programación, vistas en mi carrera como Ingeniero Multimedia en la Unad, decidí tomar este curso para mejorar mi lógica y darme cuenta de malas praxis que tenía a la hora de resolver problemas y escribir código. Aprendí buenas prácticas a la hora de nombrar variables y aplicar principios básicos de diseño de software como YAGNI, KISS, DRY. El objetivo fue afianzar la lógica de programación antes de dar el salto a un lenguaje robusto como Java. Decidí iniciar en Typescript el cual es un Superset de Javascript este recorrido para familiarizarme con lenguajes fuertemente tipados.

También repasé y apliqué conceptos del libro: Trejos Buriticá, O. I. (2023). Lógica de programación (2ª ed.). Ediciones de la U. Donde aprendí la diferencia entre la lógica humana y la lógica computacional, metodologías para pasar de un problema real a un programa computable, análisis E.P.S (entrada, proceso y salida) y el diseño de algoritmos cómo también algunos errores comunes que se suelen cometer iniciando en este bello rubro. 



## 🧠 Conceptos Aprendidos
- Variables y tipos de datos (number, string, boolean).
- Estructuras de control: `if`, `else if`, `else`, `switch`.
- Ciclos: `for`, `while`.
- Manejo de arreglos (arrays) y la propiedad `.length`.
- Operadores matemáticos (incluyendo el módulo `%` para pares/impares).
- Creación de funciones, parámetros y el uso de `return`.
- Pilares de POO 

## 📂 Ejercicios Realizados
1. **Conversión de unidades:** Libras a Kilogramos y Kilómetros a Millas.
2. **Cálculo de área:** Área de un triángulo rectángulo.
3. **Lógica de arreglos:** Encontrar el número mayor de un array usando un ciclo `for`.
4. **Lógica con módulo:** Impresión de números pares e impares.
5. **Ciclos anidados:** Impresión de una tabla del 1 al 5 con filas y columnas.
6. **Funciones y condicionales:** Función `max` que retorna el mayor de tres argumentos.

## 🛠️ Tecnologías
- TypeScript (Node.js)
